# 由来の記録（プロヴェナンス）

このリポジトリは **観測（USB バス上の転送）だけ** を入力として作られている。
参照したのは次の 3 種類のデータのみ。

| 種類 | 取得方法 | 何に使ったか |
|---|---|---|
| usbmon テキスト | `/sys/kernel/debug/usb/usbmon/1u` | レジスタ書き込み列（初期化・チャネル切替） |
| usbmon バイナリ | `tools/umon.py` | FW 転送の全体、RX フレームのレイアウト |
| 空中フレーム | `tcpdump -i wlan0 -w`（モニタモード） | RX の切り出し位置の照合 |

GPL のドライバソース（rtw88 / rtl8812au / 88x2bu）は参照していない。
`tools/` の生成器は「観測 → 表」の機械変換のみを行い、意味付けをしない。

---

## 1. 取得した捕捉（ローカルのみ・リポジトリには入れない）

| ファイル | 内容 | 用途 |
|---|---|---|
| `full2.bin` | `modprobe rtw88_8822bu` → `ip link set up` の全体 | 初期化列・FW ページ・期待読み出し値 |
| `chan/ch{1,6,11,36,44,48,149,165}.bin` | モニタモードで 1 チャネルずつ切り替えた捕捉 | チャネル表 |
| `rx6b.bin` + `mon6.pcap` | ch6 モニタ 12 秒（usbmon と tcpdump を同時取得） | RX 前置き 56 バイトの決定 |

`full2.bin` の SHA256 は `rtl8812bu/tables/init_seq.py` の先頭に、
各チャネル捕捉の SHA256（先頭 16 桁）は `tables/chan_table.py` の先頭に記録している。

## 2. RX 前置き（56 バイト）の決め方

推測ではなく照合で決めた。

1. モニタモードで usbmon と tcpdump を同時に取る。
2. pcap から 802.11 フレーム（radiotap を除いたもの）を取り出す。
3. 各フレームを usbmon のバルク IN データ内で検索する。
4. 一致位置が **195/195 すべてオフセット 56**、後続バイト 0 だった。

→ 「前置き 56 バイトの直後からフレームが始まる」と確定。
前置きの先頭 2 バイトがフレーム長（リトルエンディアン）であることも
全 210 レコードで一致した。

前置きの他のフィールドの意味は **未確定**（触らない）。

## 3. FW 転送（48 バイトヘッダ + 最大 4096 バイト）

- FW ファイルの先頭 64 バイトは送られない（65 バイト目以降を送る）。
- 1 転送 = 48 バイトのヘッダ + ペイロード。ヘッダ先頭 2 バイトがペイロード長。
- ペイロードの連結は FW 本体とほぼ一致し、11217 バイト目に 0x00 が 1 バイト
  挿入されていた（`rtl8812bu/fw.py` の `PAD_OFFSET`）。

この 3 点は捕捉した 40 転送と **バイト一致** することで検証済み
（`fw.build_stream()` の出力 == 捕捉したバルク OUT の連結）。

## 4. 生成物と生成コマンド

| 生成物 | コマンド |
|---|---|
| `rtl8812bu/tables/init_seq.py` | `python3 tools/gen_init.py /tmp/full2.bin --out rtl8812bu/tables` |
| `rtl8812bu/tables/fwdl_pages.py` | 同上（同時に出力） |
| `rtl8812bu/tables/chan_table.py` | `python3 tools/gen_chan.py /tmp/chan --out rtl8812bu/tables` |

生成物は **手で編集しない**。値の追加・修正が必要なら捕捉を取り直す。

## 5. 規格に基づく部分（観測ではない）

`rtl8812bu/ieee80211.py` は IEEE 802.11 の公開仕様に基づく独自実装。
観測データは使っていない（フレーム形式は規格で決まっているため）。

## 6. 公開時の匿名化

捕捉には実在の SSID / BSSID / MAC が含まれるため、**このリポジトリには実値を入れない**。

- 文書中の MAC アドレスは `<MAC>` に置換済み
- 実在 SSID は「チューナーAP」「近隣AP-A」等のラベルに置換済み
- 生の捕捉（usbmon / pcap）は `.gitignore` で除外し、コミットしない
- 生成物（`tables/*.py`）はレジスタ値のみで、アドレスや SSID を含まない

再現したい場合は `docs/capture.md` の手順で自分の環境の捕捉を取り、
`tools/gen_*.py` で表を生成する。
